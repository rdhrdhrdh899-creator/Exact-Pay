
# ⚡ Exact Pay — UPIPE

**Exact Pay** is a free, privacy-first **UPI QR code & payment link generator** that runs 100% in your browser. No backend, no signup, no data stored.

🔗 **Live demo:** https://exact-pay.vercel.app/

---

## ✨ Features

- **Instant QR + payment link** — enter a UPI ID, optional name, amount, and note → get a scannable QR code and a shareable UPI payment link in real time.
- **Two input tabs**
  - **UPI ID** — VPA, name, amount, note
  - **Bank Account** — account number + IFSC → auto-constructs a UPI VPA
- **Actions** — Copy Link · Download QR (branded PNG) · Share (Web Share API on mobile)
- **Scannable QR** — pure black-on-white modules with a white quiet zone for reliable scanning by all UPI apps.
- **Branded download** — the saved QR PNG includes the UPIPE logo, "Scan to pay via UPI" label, recipient name/amount, and a "Generated by UPIPE" watermark.
- **Scrolling marquee** of 6 supported UPI apps.
- **Light / Dark theme toggle** — bright light look (default) or the original deep-violet dark look, with smooth transitions and `localStorage` persistence.
- **Content sections** — Why UPIPE (6 feature cards), How to Generate (3 steps), FAQ accordion, footer.
- **Fully mobile responsive** with smooth scroll-triggered animations.

## 🛠️ Tech Stack

- **HTML + CSS + Vanilla JavaScript** — single file, zero dependencies, zero build step.
- [`qrcode.js`](https://github.com/davidshimjs/qrcodejs) via CDN for QR generation (CorrectLevel H).
- No backend · no signup · no tracking · runs entirely client-side.

## 🚀 Usage

Just open `index.html` in any modern browser — that's it. Or host it on any static host (GitHub Pages, Netlify, Vercel, etc.).

## 🔒 Privacy

Everything happens in your browser. No payment data is ever sent to a server or stored anywhere.


---

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
